# Менеджер паролей

Консольное приложение для хранения логинов и паролей в зашифрованном JSON-файле.
Мастер-пароль не сохраняется: в файле находится только его хэш PBKDF2-HMAC-SHA256.
Сами записи шифруются Fernet. Для хэша и ключа шифрования используются разные
случайные соли.

## Установка

Нужен Python 3.11 или новее. С `uv`:

```bash
uv sync --extra dev
```

Обычная установка:

```bash
python -m pip install -e ".[dev]"
```

## Запуск

Создать хранилище (мастер-пароль вводится скрыто и запрашивается дважды):

```bash
uv run python password_manager.py --init
```

Войти:

```bash
uv run python password_manager.py --unlock
```

После входа доступны команды `add`, `list`, `get`, `delete`, `exit`.
При просмотре конкретного пароля программа повторно запрашивает мастер-пароль.

Сгенерировать пароль длиной 20 символов:

```bash
uv run python password_manager.py --generate
```

Указать другую длину или путь к хранилищу:

```bash
uv run python password_manager.py --generate --length 32
uv run python password_manager.py --init --file my_vault.json
uv run python password_manager.py --unlock --file my_vault.json
```

Также после установки доступна команда `password-manager`.

## Проверка

```bash
uv run pytest
uv run ruff check .
uv run ruff format --check .
uv run mypy --strict password_manager tests
```

GitHub Actions автоматически выполняет эти проверки при каждом push и pull request.

## Как устроена защита

1. При создании хранилища генерируются две независимые случайные соли.
2. Мастер-пароль преобразуется в хэш через PBKDF2-HMAC-SHA256. В файл попадают
   соль и хэш, но не исходный мастер-пароль.
3. Из того же мастер-пароля, но с другой солью, выводится ключ Fernet.
4. Логин и пароль каждой записи шифруются перед сохранением в JSON.
5. Без успешного входа нельзя добавлять, просматривать или удалять записи.
6. Файл сохраняется через временный файл; на системах Unix для него выставляются
   права доступа `600`.

Это учебное приложение. Оно не заменяет проверенный менеджер паролей для хранения
критически важных учётных данных. Потерянный мастер-пароль восстановить нельзя.
